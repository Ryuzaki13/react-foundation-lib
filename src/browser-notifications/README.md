# Браузерные уведомления

`createBrowserNotificationPresenter` из `/browser-notifications` предоставляет
явный запрос разрешения и отменяемую публикацию системного уведомления.
Создание не обращается к браузеру; SSR не вызывает API. Метод `show` предпочитает
уже активный Service Worker, а без него использует desktop Notification API.
Приложение обрабатывает `notificationclick` своего worker, проверяя URL из data.
Серверная Web Push доставка и регистрация worker не входят в контракт.

`requestPermission` вызывается непосредственно из пользовательского жеста.
Отказ не запрашивается повторно. HTTPS/localhost и поддержка API обязательны;
системные ограничения остаются у браузера. `show` возвращает немедленный disposer,
который закрывает также позднюю SW-публикацию; `dispose` завершает все свои.
События клика desktop передаются в `onOpen`, ошибки доставки — в `onError`.

Связанные независимые primitives: `/media` экспортирует
`createNotificationTonePlayer` с плавным синусоидальным сигналом до 1,5 секунды
и явной `activate` из жеста пользователя; `/dom` предоставляет
`installFaviconOverride` с симметричным восстановлением favicon links.
Продуктовые правила, интервалы оповещения, тексты, настройки и дедупликация
остаются у вызывающего приложения.
