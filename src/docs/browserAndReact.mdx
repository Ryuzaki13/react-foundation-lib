# Browser и React API

Эти entrypoint работают только после монтирования в браузере. Вызывайте hooks на верхнем уровне React-компонента или custom hook, а императивные действия (скачивание, clipboard, открытие меню) — из event handler. Они не заменяют UI primitives из `@ryuzaki13/react-foundation-ui`.

## Общие hooks

```ts
import {
	useDebounce,
	useDebouncedCallback,
	useDndSortableSensors,
	useFloatingListbox,
	useSearchLink,
	useSearchParams,
	useThrottledCallback
} from "@ryuzaki13/react-foundation-lib/hooks";
```

| API                                                             | Назначение и lifecycle                                                                                                                 |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `useDebounce(value, delay)`                                     | Возвращает отложенное значение. Не запускает network запрос сам — используйте результат в owner Query/UI flow.                         |
| `useDebouncedCallback(callback, delay, { flushOnUnmount? })`    | Возвращает debounced callback. Опция `flushOnUnmount` нужна только когда финальный вызов действительно обязателен.                     |
| `useThrottledCallback(callback, interval, { flushOnUnmount? })` | Возвращает `{ call, flush, cancel }`; стратегия last-write-wins. Вызывайте `flush` на границе сохранения, `cancel` при смене identity. |
| `useDndSortableSensors(distanceOrOptions?)`                     | Готовые Pointer/Keyboard sensors для `@dnd-kit/sortable`; default distance — 6 px.                                                     |
| `useLazyComponent(loader, ...)`                                 | Используйте для lazy UI по устойчивому loader/cache key, а не вызывайте dynamic import во время render.                                |
| `useReferenceTrace(name, value)`                                | Development diagnostic для отслеживания смены ссылок; не часть бизнес-логики.                                                          |
| `useBlockBrowserZoom(enabled)`                                  | Подписывается на browser events для блокировки zoom. Используйте только в явном специализированном UX, не как default.                 |

### Search и floating listbox

`useSearchParams<K>(allowedKeys?)` и `useSearchLink<K>()` требуют `@tanstack/react-router`. Первый возвращает `{ params, filteredParams, setParams }` и выполняет navigation с `replace: true`; второй возвращает `buildLink(params)`. Оба работают с URL state, а не с произвольным Zustand/local store.

`useFloatingListbox<T>(options)` требует `@floating-ui/react` и объединяет ref, ARIA-interactions, keyboard navigation и placement. Передавайте:

- `options`, `selectedIndex`, `getOptionDisabled` — данные и доступность опций;
- optional controlled `open` + `onOpenChange`;
- `onSelect`, `closeOnSelect`, `focusFloatingOnOpen`, `restoreFocusOnClose` — interaction policy;
- `placement` и `placementStrategy: "flip" | "auto"` — placement;
- `resolveFloatingSize(context)` — только layout/CSS size policy.

Hook возвращает Floating UI props/refs и их нужно распространять на reference, floating element и options строго по его контракту. Не заменяйте эти props самодельными keyboard handlers: это нарушит `aria-activedescendant`, focus restore и cleanup `autoUpdate`.

## DOM и overlay helpers

```ts
import {
	downloadFileFromBlob,
	getOrCreatePortalRoot,
	useClickOutside,
	useEscapeDismiss,
	useFocusTrap,
	useIntersectionObserver,
	useOverlayFocus
} from "@ryuzaki13/react-foundation-lib/dom";
```

| API                                              | Контракт                                                                                                      |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `downloadFileFromObjectURL(filename, objectUrl)` | Инициирует download по готовому object URL; не владеет временем `URL.revokeObjectURL`.                        |
| `downloadFileFromBlob(filename, blob)`           | Создаёт временный object URL и инициирует download.                                                           |
| `downloadFileFromJson(filename, payload)`        | Сериализует payload в JSON blob и скачивает.                                                                  |
| `getOrCreatePortalRoot(id)`                      | Возвращает/создаёт DOM root или `null`, если `document` недоступен.                                           |
| `useClickOutside(refOrRefs, handler)`            | Вызывает handler при внешнем pointer interaction; передавайте стабильные refs.                                |
| `useEscapeDismiss(options)`                      | Dismiss только для active/enabled overlay; поддерживает container и целевой document.                         |
| `useFocusTrap(isOpen)`                           | Возвращает ref для trapping focus внутри открытого overlay.                                                   |
| `useOverlayFocus(options)`                       | Управляет initial focus и restore для overlay; применяйте вместе с accessible dialog/menu.                    |
| `useElementHeightObserver(ref)`                  | Следит за высотой через `ResizeObserver`; результат используйте для layout, не для копирования props в state. |
| `useIntersectionObserver(ref, options?)`         | Возвращает intersection state DOM element.                                                                    |
| `useIsTouchDevice()`                             | Реактивно сообщает touch-capability браузера.                                                                 |

Hooks сами подписываются и очищают observers/listeners при unmount. Не вызывайте `getOrCreatePortalRoot` или browser API в server render; hook-проверки не делают UI SSR-safe автоматически.

## Clipboard, media и context menu

```ts
import { useCopyText, useCopyElementTextWithFeedback } from "@ryuzaki13/react-foundation-lib/copy";
import { useMediaQuery, useMatchMedia, resolveResponsiveValue } from "@ryuzaki13/react-foundation-lib/media";
import { createVirtualAnchor, openMenu } from "@ryuzaki13/react-foundation-lib/context-menu";
```

### `copy`

| API                                   | Результат                                                         |
| ------------------------------------- | ----------------------------------------------------------------- |
| `useCopyText()`                       | Возвращает copy action для строки через Clipboard API с fallback. |
| `useElementText(ref)`                 | Читает текст из DOM element.                                      |
| `useCopyElementText(ref)`             | Комбинирует чтение элемента и copy.                               |
| `useCopyFeedback()`                   | Локальное временное состояние feedback после успешного copy.      |
| `useCopyElementTextWithFeedback(ref)` | Удобная композиция copy element + feedback.                       |

Copy может быть отклонён browser permissions; показывайте ожидаемую UI-ошибку, но не считайте clipboard источником истины для сохранения данных.

### `media`

`BREAKPOINTS_EM` и `Breakpoint` задают стандартные breakpoints; `useMatchMedia()` возвращает `MediaMatches`. Для конкретного media query используйте `useMediaQuery(query, { ssrFallback? })`; `ssrFallback` определяет значение только до browser hydration/в окружении без `matchMedia`.

`ResponsiveValue<T>`, `isResponsiveMap`, `resolveResponsiveValue` и `resolveProps` — pure helpers для responsive props. `getCurrentFontSize`, `getCurrentLineHeight`, `getControlHeight`, `pxToEm` читают layout/DOM: не вызывайте их в render, если результат влияет на state без external synchronization.

### `context-menu`

`MenuAnchor`, `MenuState`, `MenuPoint`, `OpenMenuPayload` — serializable contracts состояния меню. `openMenu(payload)`, `closeMenu(state)` и `toggleMenu(state, payload)` — pure reducers; их можно держать в local/store owner.

Для pointer menu используйте `getMenuPointFromEvent(event)` и `createVirtualAnchor(point, contextElement?)`. Для keyboard anchor используйте `getMenuPointFromRect(rect)`. API лишь описывает состояние/anchor; отображение и accessibility menu остаются у UI-компонента.

## Virtualizer, PWA и Three.js

### Infinite virtualizer

```ts
import { useFetchNextPageEffect } from "@ryuzaki13/react-foundation-lib/virtualizer";
```

Hook принимает `{ virtualItems, currentItemsCount, hasNextPage, fetchNextPage }`; при достижении последней виртуальной строки запускает один следующий fetch и не создаёт параллельные запросы. `fetchNextPage` должен быть стабильным Query action. Не передавайте raw `fetch` и не подменяйте backend state локальным массивом.

### Service Worker

```ts
import { parseSwCachePolicy, buildSwCachePolicyValue, useServiceWorkerUpdate } from "@ryuzaki13/react-foundation-lib/pwa";
```

`useServiceWorkerUpdate()` возвращает `{ hasUpdate, applyUpdate, dismiss }`. Его задача — UI-поверхность для уже настроенного приложения с Service Worker; hook не публикует и не настраивает private registration API.

`pwa/sw-cache-policy` — отдельный точечный import того же pure policy API:

| API                                      | Контракт                                                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `parseSwCachePolicy(value)`              | Парсит `off`, `ttl=<duration>` или `bust=<duration>` с `max`/`name`; invalid input даёт `undefined`. |
| `buildSwCachePolicyValue(draft)`         | Нормализует `SwCachePolicyDraft` в canonical transport string.                                       |
| `normalizeSwCacheName(value)`            | Делает безопасное lower-case cache name или `undefined`.                                             |
| `resolveSwCacheCacheNameByPolicy(value)` | Возвращает вычисленное имя cache только для `ttl`/`bust`.                                            |

Пример: `ttl=24h;max=200;name=reference`. Это policy для transport/Service Worker, а не замена TanStack Query cache. Не включайте в SW cache auth-sensitive responses без отдельной security policy.

### Доступность Three.js

```ts
import { useThreeSceneAvailability, disableThreeSceneForSession } from "@ryuzaki13/react-foundation-lib/three-scene";
```

| API                                                                         | Назначение                                                                                                                    |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `isThreeSceneSupported(options?)`                                           | Проверяет browser WebGL/WebGL2 support.                                                                                       |
| `isThreeSceneDisabledForSession(key?)`, `disableThreeSceneForSession(key?)` | Читают/устанавливают opt-out текущей tab session.                                                                             |
| `useThreeSceneAvailability(options?)`                                       | React state с `pending`/`available`/`unavailable` и причиной (`sessionDisabled`, `reducedMotion`, `webglUnsupported`, `ssr`). |

Проверка support не заменяет обработку ошибки renderer. При `unavailable` всегда рендерите семантический non-Three fallback.
