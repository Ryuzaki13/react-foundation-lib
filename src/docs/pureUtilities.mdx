# Чистые utilities и contracts

Эти API не создают global state и обычно не требуют React. Они полезны в entity/feature code, если задача остаётся предметно-независимой. Не переносите в них доменные правила только ради повторного использования.

## Коллекции, порядок и ограниченная история

```ts
import { arrayGroupBy, arrayUniqueBy, moveArrayItem } from "@ryuzaki13/react-foundation-lib/array";
import { pushBoundedCopyStackItem } from "@ryuzaki13/react-foundation-lib/bounded-copy-stack";
```

| API                                                                    | Поведение                                                                                                  |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `arrayGroupBy`, `arrayGroupByToArray`, `arrayToMap`                    | Группируют/индексируют по полю объекта. `arrayToMap` оставляет первое значение ключа.                      |
| `arrayUniqueBy`, `arrayDeduplicate`                                    | Immutable deduplication с сохранением первого встретившегося значения/порядка.                             |
| `filterAndDeduplicateIds`, `appendMissingIds`, `pickExistingMapValues` | Helpers для stable id lists и ordered Map values.                                                          |
| `arraysEqual`                                                          | Строго сравнивает длину, порядок и значения по `===`.                                                      |
| `moveItem`, `moveArrayItem`, `moveArrayItemByIndex`                    | Возвращают новую переставленную коллекцию; invalid indices не мутируют input.                              |
| `normalizeObjects`, `normalizeStringArray`, `addUnique`                | Explicit canonicalization для внешней/сохранённой структуры — не вызывайте её внутри literal draft setter. |

`pushBoundedCopyStackItem(stack, input, options?)` добавляет/поднимает item по `fingerprint` и ограничивает размер (default `DEFAULT_BOUNDED_COPY_STACK_SIZE = 3`). `getBoundedCopyStackCandidates` фильтрует готовый stack predicate-ом. `BoundedCopyStackItem`, `BoundedCopyStackPushInput`, `BoundedCopyStackOptions` и `BoundedCopyStackPushResult` описывают его serializable contract.

## Значения, шкалы и календарные сегменты

```ts
import { parseDateSegmentMask, indexedSegmentsToDate } from "@ryuzaki13/react-foundation-lib/date-segments";
import { snapNumberScaleValue } from "@ryuzaki13/react-foundation-lib/number-scale";
import { resolveRangeOutputValue } from "@ryuzaki13/react-foundation-lib/range-output";
```

| Entry point         | Основной API                                                                                                                                                                                                                                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `date-segments`     | `parseDateSegmentMask`, `isEditableDateSegment`, `dateToIndexedSegmentValues`, `areAllDateSegmentsEmpty`, `indexedSegmentsToDate`. `indexedSegmentsToDate` строго отвергает невозможную дату/время; `DateMaskSegment` описывает editable/literal segments.                                                               |
| `number-scale`      | `resolveNumberScaleBounds`, `clampNumberScaleValue`, `normalizeNumberScaleStep`, `prepareNumberScaleMarks`, `snapNumberScaleValueToStep`, `snapNumberScaleValueToMarks`, `snapNumberScaleValue`, `valueToNumberScalePercent`, `percentToNumberScaleValue`, `percentToSnappedNumberScaleValue`, `offsetNumberScaleValue`. |
| `currency`          | `resolveCurrencyModeFromODataParameters` и `resolveCurrencyAwareLabel`; это label policy по wrapped OData parameters, не currency formatter.                                                                                                                                                                             |
| `range-output`      | `readRangeOutputValueFallback` и `resolveRangeOutputValue`; подставляет fallback только для `null` открытой границы и не меняет исходный UI range.                                                                                                                                                                       |
| `presets`           | `normalizePresetIds`, `resolvePresetOptionsByIds`, `getPresetOption`, `PresetOption`; помогает на save/restore boundary для известного набора IDs.                                                                                                                                                                       |
| `string-comparison` | `compareStrings(left, right)` использует fixed Russian numeric/case-insensitive collation с deterministic fallback.                                                                                                                                                                                                      |

Для date/number UI formatting используйте `formatters`, а не `number-scale`/`currency`.

## Clone, строки, keyboard и trees

```ts
import { cn, deepCloneWithoutFunctions, deepCopyWithoutFunctions, stableStringify } from "@ryuzaki13/react-foundation-lib/utils";
```

| API                                                                                                  | Контракт                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cn(...args)`                                                                                        | Собирает className из строк и conditional object. `classNames` — deprecated alias; новый код использует `cn`.                                                       |
| `stableStringify(value)`                                                                             | JSON-like stable serialization с сортировкой object keys — для key/comparison, не как универсальный persistence format.                                             |
| `deepCopyWithoutFunctions(value, options?)`                                                          | Копирует Date, arrays и plain objects, поддерживает cycles; функции пропускает. Unsupported object бросает `TypeError`. Предназначен для serializable plain config. |
| `deepCloneWithoutFunctions(value, options?)`                                                         | Расширенный clone: Date, RegExp, Map, Set, cycles, sparse arrays и optional prototype. Функции пропускает.                                                          |
| `createLazyComponent`, `childrenCount`                                                               | React-adjacent helpers для stable lazy component и correct children count.                                                                                          |
| `keyboardActivationKeys`, `isKeyboardActivationKey`, `handleKeyboardActivation`                      | Keyboard activation contract для custom control.                                                                                                                    |
| `getRovingFocusTargetIndex`, `findFirstEnabledIndex`, `findLastEnabledIndex`, `findNextEnabledIndex` | Pure navigation для listbox/select с disabled/wrap.                                                                                                                 |
| `deepCopyNodes`, `deepCopyTree`                                                                      | Копирование tree nodes с standard/custom children field.                                                                                                            |
| `toBase64`, `encodeBase64`, `logError`                                                               | Unicode-safe base64 и centralised error logging.                                                                                                                    |

Clone не является нормализацией: он создаёт независимую структуру в пределах собственного contract и не должен применять trim, defaults, deduplication или reorder к пользовательскому draft. Для plain serializable config используйте `deepCopyWithoutFunctions`, а не `structuredClone`.

## Runtime guards и базовые типы

```ts
import { asRecord, isRecord, isSafe, readPositiveInteger } from "@ryuzaki13/react-foundation-lib/validators";
import type { BaseType, RangeType, RowRecord, State } from "@ryuzaki13/react-foundation-lib/types";
```

| API                                                 | Когда использовать                                                         |
| --------------------------------------------------- | -------------------------------------------------------------------------- |
| `isSafe`                                            | Убирает только `null`/`undefined` из union.                                |
| `isObject`, `isRecord`, `asRecord`, `isPlainObject` | Narrow unknown external value до object/record; array не считается record. |
| `readPositiveInteger`                               | Возвращает positive integer или `undefined` без unsafe cast.               |
| `validateUrl`                                       | Возвращает validation result для строки URL.                               |
| `IMAGE_EXTENSIONS`, `isImageExtension`              | Проверка расширения без учёта регистра; не MIME/security validation.       |
| `isDomReference`                                    | Floating UI reference → DOM `Element` guard.                               |

`State`, `AbapBoolean`, `Primitive`, `BaseType`, `ArrayType`, `ObjectType`, `InputType`, `RangeType`, `RowRecord`, `isBaseType` — общие low-level contracts. Не используйте `RowRecord` как модель конкретной доменной сущности.

## Идентификаторы, HTTP, XML, SEO и form errors

| Entry point       | API                                                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `crypto`          | `hashString`, `hashString128`, `hashString128Base64Url`, `stringToElementId`, `uuidv4`. Hash служит для stable client key, не криптографической защиты.             |
| `session-storage` | `getSessionStorageId(key, createId?)` — scoped browser-tab id; не authentication token.                                                                             |
| `http`            | `createNoStoreHeaders(init?)` создаёт Headers с no-store; `createTextHttpResponse(options)` создаёт text `Response`.                                                |
| `xml`             | `escapeXmlValue`, `buildXmlFields`, `getXmlTagText` для небольших XML fragments. Не применяйте regex helper как универсальный XML parser для untrusted complex XML. |
| `seo`             | `createSeoHead(options)`, `createRouteHead(type, path, params)` создают `meta`, `links`, JSON-LD `scripts`; host router/head owner решает, как применить результат. |
| `form`            | `readFirstFormError(errors?)` выбирает первое readable error message из unknown error array.                                                                        |
| `error`           | `createMissingContextErrorMessage`, `createMissingContextError` формируют единообразную ошибку отсутствующего React Provider.                                       |

`fingerprint` и `notifications` описаны на странице Runtime/state, потому что имеют browser/global lifecycle.
