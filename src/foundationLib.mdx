# `@ryuzaki13/react-foundation-lib`

Технический фундамент для host-приложений: чистые преобразования данных, browser/React hooks, сериализуемые runtime-контракты, OData metadata helpers и инфраструктура состояния. Пакет не знает домен приложения, UI-компоненты и transport конкретного backend.

## Подключение

```bash
npm install @ryuzaki13/react-foundation-lib
```

Пакет ESM и намеренно **не имеет корневого импорта**. Подключайте ровно тот опубликованный subpath, который нужен сценарию:

```ts
import { formatDateAsDate } from "@ryuzaki13/react-foundation-lib/formatters";
import { createQueryClient } from "@ryuzaki13/react-foundation-lib/query-client";
import type { RowRecord } from "@ryuzaki13/react-foundation-lib/types";
```

```ts
// Неверно: корневой entrypoint не опубликован.
import { formatDateAsDate } from "@ryuzaki13/react-foundation-lib";
```

## Граница ответственности

| Задача                                                     | Использовать                              | Не использовать вместо этого         |
| ---------------------------------------------------------- | ----------------------------------------- | ------------------------------------ |
| Чистые OData V2 metadata, path, filter и value helpers     | `odata-service`                           | HTTP/OData transport                 |
| Вызовы SAP Gateway, SSO, X-CSRF и TanStack Query operation | `@ryuzaki13/react-foundation-api/odata`   | ручной `fetch` или этот пакет        |
| UI primitives и дизайн-система                             | `@ryuzaki13/react-foundation-ui/<module>` | hooks/utilities из lib как компонент |
| Доменный mapping и пользовательский сценарий               | host entity/feature                       | foundation-lib                       |

`react-foundation-lib` не создаёт бизнес-правила, не хранит backend snapshot и не заменяет API- или UI-пакеты.

## Среда выполнения и peer dependencies

Большинство pure helpers не требуют React. Entry point с React hook, DOM, browser storage или Service Worker должен вызываться только в браузерном runtime и по правилам React hooks. Совместимые peer dependencies должны быть разрешены host-проектом для используемого entrypoint.

| Возможность                                     | Когда нужна в host                                                                         |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `react`                                         | `hooks`, `dom`, `copy`, `media`, `pwa`, `three-scene`, selection/table и OData store hooks |
| `@tanstack/react-query`, persistence, broadcast | `query-client`, часть `error-report`                                                       |
| `@tanstack/react-table`                         | `table`                                                                                    |
| `@tanstack/react-virtual`                       | `virtualizer`                                                                              |
| `@tanstack/react-router`                        | search helpers из `hooks`                                                                  |
| `@floating-ui/react`                            | `useFloatingListbox`, DOM reference guards                                                 |
| `@dnd-kit/core`, `@dnd-kit/sortable`            | `useDndSortableSensors`                                                                    |
| `zustand`, `immer`, `zod`                       | единый `odata-service`: collection store и OData schemas                                   |
| `zustand`                                       | `notifications`                                                                            |
| `write-excel-file`                              | `excel`                                                                                    |
| `@fingerprintjs/fingerprintjs`                  | `fingerprint`                                                                              |

## Как читать справочник

Каждая последующая страница построена вокруг **published subpath**, а не каталога исходников. В ней указаны точный import, публичные contracts, обязательная инициализация, результат, lifecycle/cleanup и ограничения. Для pure helpers достаточно вызвать функцию; registry, browser и global-store API требуют отдельного раздела «Инициализация и side effects».

Связанные entrypoint `table` и `tree-table` описаны на одной странице [Table и Tree Table](./table/README.mdx): документ общий, но публичные import path остаются раздельными.

Для общего entrypoint clone, className, keyboard, stable stringify, lazy React components и tree helpers доступен подробный справочник [Utils](./utils/README.mdx).
