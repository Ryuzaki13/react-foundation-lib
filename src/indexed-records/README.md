# Индексированные записи

Предметно независимый public API для снимков с устойчивым порядком записей.
Форма сценарных и справочных wire contracts выбирается их владельцами отдельно.
Этот модуль не владеет Query, ревизиями, сериализацией,
серверным кэшем или проверкой предметной идентичности.

```ts
import { createIndexedRecords, getIndexedRecord } from "@ryuzaki13/react-foundation-lib/indexed-records";

const snapshot = createIndexedRecords(items, (item) => item.id);
const item = getIndexedRecord(snapshot, selectedId);
```

`IndexedRecords<T>` содержит один исходный `readonly items` и
`Readonly<Record<string, number>> indexById`. Индекс хранит позиции, а не вторую
копию записей. `createIndexedRecords` строит его за один проход; повторная
identity вызывает ошибку. Порядок и ссылки исходного массива сохраняются.

`getIndexedRecord` выполняет адресный lookup и возвращает запись исходного
массива либо `undefined`. IDs сравниваются без нормализации; строковые keys
`__proto__`, `constructor`, пустая строка и числовые строки безопасны.

Владелец снимка вызывает создание один раз при появлении новой версии и
переиспользует результат. Между чтениями нельзя изменять порядок массива,
состав записей или их identities. Модуль замораживает только созданные им
контейнер и индекс: он не копирует и не замораживает чужие массивы, записи или
вложенные объекты. Неизменность полей `T` задаётся предметным контрактом.

Восстановленные недоверенные данные должны пройти проверку у принимающей
границы. Наличие полей `items` и `indexById` само по себе не подтверждает
корректность позиций, полноту или уникальность каталога.
