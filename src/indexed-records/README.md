# Индексированные записи

Предметно независимый public API для снимков с устойчивым порядком записей.
Форма сценарных и справочных wire contracts выбирается их владельцами отдельно.
Этот модуль не владеет Query, ревизиями, сериализацией,
серверным кэшем или проверкой предметной идентичности.

```ts
import { createIndexedRecords, getIndexedRecord } from "@ryuzaki13/react-foundation-lib/indexed-records";

const snapshot = createIndexedRecords(items, (item) => item.id);
const item = getIndexedRecord(snapshot, selectedId);
```

`IndexedRecords<T>` содержит один исходный `readonly items` и
`Readonly<Record<string, number>> indexById`. Индекс хранит позиции, а не вторую
копию записей. `createIndexedRecords` строит его за один проход; повторная
identity вызывает ошибку. Порядок и ссылки исходного массива сохраняются.

`getIndexedRecord` выполняет адресный lookup и возвращает запись исходного
массива либо `undefined`. IDs сравниваются без нормализации; строковые keys
`__proto__`, `constructor`, пустая строка и числовые строки безопасны.

Владелец снимка вызывает создание один раз при появлении новой версии и
переиспользует результат. Между чтениями нельзя изменять порядок массива,
состав записей или их identities. Модуль замораживает только созданные им
контейнер и индекс: он не копирует и не замораживает чужие массивы, записи или
вложенные объекты. Неизменность полей `T` задаётся предметным контрактом.

Восстановленные недоверенные данные должны пройти проверку у принимающей
границы. Наличие полей `items` и `indexById` само по себе не подтверждает
корректность позиций, полноту или уникальность каталога.

## Проверка доставленного индекса

Optional entry со схемой требует Zod 4. Прежний `indexed-records` entry не
импортирует его и сохраняет работу без Zod.

```ts
import { z } from "zod";
import { createIndexedRecordsSchema } from "@ryuzaki13/react-foundation-lib/indexed-records/schema";

const recordsSchema = createIndexedRecordsSchema({
	itemsSchema: z.array(z.strictObject({ id: z.string(), name: z.string() }).readonly()).readonly(),
	getId: (item) => item.id
});

const records = recordsSchema.parse(deliveredRecords);
```

Схема принимает только строгую оболочку `{ items, indexById }`. `itemsSchema`
проверяется один раз; её порядок, массив и записи переиспользуются без
дополнительной копии. Доставленный индекс проверяется и копируется одним
проходом. Каждая собственная identity должна указывать на целую допустимую
позицию своей записи; все записи должны быть покрыты ровно один раз.
Отсутствующие/лишние ключи, повторяющиеся identities, переставленные позиции,
accessor, symbol, нестандартный prototype и нечисловые значения отклоняются.
Строковые IDs, включая пустую строку, `__proto__` и числовые строки, не
нормализуются; числовой ID предмета можно преобразовать в `getId` через `String`.

Фабрика не строит индекс из массива, не сортирует записи и не знает их
предметной семантики. `getId` должен быть чистым и возвращать устойчивую
каноническую identity. Выходная оболочка и собственный null-prototype индекс
заморожены. Freeze массива, записей и вложенных объектов, а также межстрочные
предметные ограничения задаёт `itemsSchema` владельца. Generic recursive
freeze, второй parse записей, сертификаты, revision и cache сюда не входят.
