# Документ редактируемой таблицы

Public API: `@ryuzaki13/react-foundation-lib/table-document`.

Чистое ядро для конструктора таблиц. Полная прямоугольная матрица хранит значения
всех ячеек, а отдельный массив `merges` — непересекающиеся объединения. Merge
никогда не удаляет содержимое покрытых ячеек; split возвращает их видимость.
Значения generic: приложение владеет rich text, ссылками, DTO и сериализацией.

Команды возвращают новый документ без мутации исходного. Неизменённые строки
и значения сохраняются по ссылке, что позволяет строить историю undo/redo.
Выделение замыкается по всем пересечённым объединениям до неподвижной точки.
Заголовок не объединяется и не переставляется с body. Вставка внутри области
увеличивает span; удаление и перемещение работают с неразрывной группой.
Перед удалением UI должен показать фактический размер группы и подтвердить его.

`assertTableDocument` проверяет геометрию типизированного документа, но не
заменяет runtime-парсер неизвестного JSON на внешней границе приложения.
Лимит — 20 000 логических ячеек. ID должны быть непустыми и уникальными во всём
документе. Генерацию ID выполнять в обработчике события, не во время render.

Это новый additive API, существующий `/table` и его selection contracts не
изменяются. Миграцию базы потребителя пакет не выполняет.
